# What Revit Wants

Public publication repository for the WRW blog. The editing master is local WordPress; verified public bundles are stored as immutable release assets and deployed by GitHub Actions.

Canonical destination: https://wrw.blackgrid.com.au/

[Black Grid](https://blackgrid.com.au/) · [WRW source and hosting framework](https://github.com/LukeyJohnson/bg-wrw) (private)

Only published blog content and publication code belong here. SQL, WordPress files, backups and credentials are excluded. The first project-domain deployment is a noindex preview while the custom domain is prepared.
